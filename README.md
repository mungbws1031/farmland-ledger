# 농지 임대 상황 보기

아버지 명의 땅의 계약일·만료일·임차인과 법정 통지·신고 마감을 가족이 함께 보는 웹앱입니다.

- 화면: GitHub Pages (이 저장소) — 링크만 열면 바로 보임, 로그인 없음
- 데이터: 구글 시트 「농지 임대 장부 (데이터)」의 `땅 목록`, `연락처` 탭
- 고치기: 구글 시트에서 엑셀처럼 고치면 앱에 반영됨 (앱 위쪽 '새로고침')

만든이: 노미희 · 2026.11.03 · ver.1.0

## 처음 설정 (한 번만)

1. 구글 시트를 열고 오른쪽 위 **공유**를 누릅니다.
2. **일반 액세스**를 **링크가 있는 모든 사용자 · 뷰어**로 바꿉니다.
3. 아버지도 시트를 고치시려면, 같은 공유 창에서 아버지 이메일을 **편집자**로 추가합니다.
4. 저장소 **Settings → Pages**에서 Branch를 `main` / `/ (root)`로 저장합니다.
5. 가족에게는 `https://계정.github.io/farmland-ledger/?s=시트ID` 형태의 링크를 보냅니다. (시트ID는 시트 주소의 `/d/` 와 `/edit` 사이) 한 번 열면 그 휴대폰이 기억합니다.
6. 아이폰은 그 링크를 **Safari**로 연 상태에서 공유 버튼 → **홈 화면에 추가**를 눌러야 아이콘으로도 장부가 열립니다. (아이콘으로 열었는데 장부가 안 보이면, 화면의 칸에 가족 링크를 붙여 넣으면 됩니다.)

이 저장소에는 시트 주소나 장부 내용이 들어 있지 않습니다. 시트 주소가 붙은 링크는 가족에게만 보내 주세요.
