# 우리 땅 임대 장부

아버지 명의 땅의 계약일·만료일·임차인과 법정 통지·신고 마감을 가족이 함께 보는 웹앱입니다.

- 화면: GitHub Pages (이 저장소)
- 데이터: 구글 시트 「우리 땅 임대 장부 (데이터)」 — `leases`, `contacts` 두 탭
- 연결: 시트에 붙인 Apps Script(`apps-script/Code.gs`) — 가족 비밀번호가 맞을 때만 읽고 씀

이 저장소에는 장부 내용(지번, 임차인, 연락처)이 들어 있지 않습니다. 모든 데이터는 구글 시트에만 있습니다.

## 처음 설정 (한 번만)

1. 구글 시트 「우리 땅 임대 장부 (데이터)」를 엽니다.
2. 메뉴 **확장 프로그램 → Apps Script**를 엽니다.
3. 기본 `Code.gs` 내용을 지우고, 이 저장소의 `apps-script/Code.gs` 내용을 그대로 붙여 넣고 저장합니다.
4. 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성 → 스크립트 속성 추가**
   - 속성: `FAMILY_PASSWORD`
   - 값: 가족끼리 쓸 비밀번호 (숫자·글자 섞어 8자 이상 권장)
5. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
   - **배포**를 누르고 권한을 승인합니다. ("확인되지 않은 앱" 경고가 나오면 '고급 → 이동'을 누르면 됩니다. 내 시트에 내 스크립트를 연결하는 것이라 정상입니다.)
6. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해 `config.js`의 `scriptUrl`에 넣습니다.
   - 넣지 않아도 첫 화면에서 주소를 직접 입력할 수 있습니다.

## 아버지와 공유

- GitHub Pages 주소와 가족 비밀번호를 아버지께 알려 드립니다.
- 처음 한 번 비밀번호를 입력하면 그 휴대폰에서 기억합니다.
- 다른 사람이 Pages 주소를 알아도 비밀번호 없이는 장부를 볼 수 없습니다.
- 비밀번호를 바꾸려면 Apps Script의 스크립트 속성 `FAMILY_PASSWORD` 값만 바꾸면 됩니다. 각 기기에서 다시 입력하게 됩니다.

## 기한 계산 규칙

| 알림 | 적용 | 계산 | 근거 |
| --- | --- | --- | --- |
| 계약 끝낼지 알리는 마감 | 개인 간 임대 | 만료일 − 3개월 | 농지법 제25조 |
| 농지대장 신고 마감 | 개인 간 임대 | 시작일 + 60일 | 농지법 제49조의2 |
| 계약 만료 | 전체 | 만료일 | 계약서 |
| 따로 챙길 날짜 | 전체 | 직접 입력 | — |

농지은행 위탁 땅의 갱신·임차인 교체 절차는 관할 지사에 확인해야 합니다. 이 앱은 법률 자문이 아닙니다.

## 시트 직접 고치기

시트에서 바로 고쳐도 됩니다. 날짜는 `2027-03-14`처럼, 참/거짓 칸은 `TRUE`/`FALSE`로 적습니다.
`addresses`, `parcelCodes`, `issues` 칸은 앱이 쓰는 형식(JSON)이므로 앱 화면에서 고치는 것이 안전합니다.
`kind` 값: `wituk`(농지은행 위탁), `private`(개인 간 임대), `forest`(임야), `self`(자경), `idle`(휴경·미임대)
